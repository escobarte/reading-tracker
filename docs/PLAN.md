## ПРИНЦИПЫ ПРОДУКТА

1. **Только учёт.** Приложение ничего не читает за вас: книги бумажные или в вашей читалке. Внутри нет ридера, только записи о чтении.
2. **Mobile-first, одной рукой.** Android, PWA. Главные действия в нижней части экрана. ПК второстепенен, но у него свой простой вид: на широком экране боковая панель и колонки, а не растянутый телефон.
3. **Один человек.** Только владелец. Вход и права доступа максимально простые.
4. **Только онлайн.** Без офлайн-режима и синхронизации.
5. **Меньше касаний.** Начать сессию и сохранить прогресс должно быть быстро.
6. **Данные ваши.** Экспорт всего в любой момент.
7. **Язык интерфейса:** русский и английский, с переключателем. Книги и заметки на русском, английском и румынском.
8. **Светлая тема по умолчанию**, тёмная как вариант. Стиль: лёгкий стичпанк.
9. **Нет импорта из Notion.** Начинаем с чистой базы.
10. **Два вида с Фазы 3.** Каждый экран делается сразу в двух видах: телефон и ПК. Отдельной «переделки под ПК» в конце не будет.

## ИТОГОВЫЙ СТЕК

| Слой | Выбор |
|---|---|
| Фреймворк | Next.js (App Router) + TypeScript |
| Стили | Tailwind CSS + дизайн-токены (светлая и тёмная тема) |
| База, вход, файлы | Supabase (Postgres, Auth, Storage для фото страниц) |
| Данные о книгах | Google Books API (запасной: Open Library) |
| Распознавание текста со страницы | Claude Vision через серверный route handler |
| Напоминания | Web Push (Android PWA) |
| Языки интерфейса | i18n: RU / EN |
| Хостинг | Vercel |

## МОДЕЛЬ ДАННЫХ (черновик)

- **books**: название, автор, обложка, `total_pages`, формат (`paper` / `ebook`), полка (`want` / `reading` / `done` / `paused`), позиция в очереди, серия и номер тома, жанр, теги, `google_books_id`, `isbn`, язык
- **readings** (прочтения книги, обычно одно, для перечитывания несколько): `book_id`, даты начала и конца, оценка, итоговая заметка, причина паузы
- **sessions**: `reading_id`, начало и конец сессии (с временем суток), страница «с» и «по», страниц прочитано, секунд на чтение, источник (таймер или ручной ввод)
- **notes**: `book_id`, тип (`quote` / `thought` / `word`), текст, значение (для слов), страница, ссылка на фото, избранное, теги
- **goals**: годовая (число книг, сейчас 24), дневная (страницы, сейчас 30), дедлайн по книге (`reading_id`, дата, дни без чтения)
- **settings**: язык, тема, время напоминания

**Считается на лету, не хранится:** текущая страница, остаток, прогресс, скорость (стр/час), средний заход, прогноз окончания, серия дней, итоги за период, недельная цель (дневная × 7), распределение по времени суток.

**Электронные книги:** прогресс можно вводить страницей или процентом. Проценты сразу пересчитываются в страницы по `total_pages`.

**Время:** в базе UTC, показ в часовом поясе владельца (Europe/Bucharest), неделя начинается в понедельник.

## ФАЗА 1.5 — Вид для ПК ⬜

**Цель:** на компьютере приложение выглядит как приложение для компьютера, а не растянутый телефон. Делаем просто и один раз, дальше каждый экран сразу в двух видах.

- Макет ПК: главная (и один экран списка для примера), в том же стиле (делает штаб до кода)
- `DESIGN.md`: раздел «Компьютер»: порог переключения (от 1024 px), боковая панель, ширина контента, правила колонок
- AppShell: от 1024 px нижняя навигация заменяется боковой панелью слева (те же пять пунктов, «Старт» кнопкой сверху панели), контент в широкой области до 1200 px
- Сетка колонок для экранов (2–3 колонки), на телефоне всё как сейчас
- Проверка, что вид телефона не изменился (360 и 390 px)

**Готово, когда:** на ширине 1280 px видна боковая панель и широкая область контента, на 360–430 px ничего не изменилось.

## ФАЗА 2 — База и вход ⬜

- Проект Supabase, таблицы по модели данных
- Вход только для владельца, сессия сохраняется
- Row Level Security на всех таблицах
- Серверные хелперы для работы с БД

**Готово, когда:** после входа можно создать и прочитать тестовую запись, без входа данные недоступны.

## ФАЗА 3 — Библиотека и добавление книги ⬜

- Добавление книги (экран `Add`): поиск в Google Books через серверный route handler, список вариантов с обложками (русские и английские издания), автозаполнение, ручная правка любого поля, подсказка про неточные страницы
- При добавлении выбираются формат (бумажная / электронная) и полка (хочу прочитать / читаю сейчас)
- Запасной вариант: Open Library; полностью ручное добавление без поиска
- Защита от дублей
- Библиотека (экран `Library`): полки с счётчиками, фильтры по формату, очередь с номерами и перетаскиванием, пометка «следующая»
- Страница книги (экран `Book`): данные, выбор полки, прогресс, плитки (время, сессии, скорость), заглушки дедлайна, заметок и истории
- Серии и тома, жанр, теги, поиск по библиотеке

**Готово, когда:** книга добавляется за 3 касания, перемещается между полками, очередь переставляется.

## ФАЗА 4 — Сессии чтения ⬜

**Главная функция приложения.**

- Экран таймера (`Session`): большое стежковое кольцо с временем, книга и стартовая страница, пауза, «Завершить», быстрые «+ цитата» и «+ фото» (пока ведут в заглушку заметок)
- Таймер хранит время старта, поэтому работает при заблокированном экране и после перезапуска приложения
- Экран завершения (`Finish`): ввод «остановился на странице» (Stepper с быстрыми +5, +10, +20), переключатель «Страницы / Проценты» для электронных книг, расчёт «прочитано N стр., скорость», итог за день и серия, «Сохранить», «Удалить»
- Ручной ввод сессии (страницы от и до, минуты, дата), если забыли включить таймер
- Правка и удаление сессии, полная история на странице книги
- Несколько книг в чтении одновременно
- Автоматический перевод книги в «Прочитано» на последней странице
- Прочтения: перечитывание создаёт новое прочтение со своей статистикой

**Готово, когда:** от открытия приложения до сохранённой сессии не больше нескольких касаний, таймер выживает при блокировке экрана.

## ФАЗА 5 — Главная ⬜

Витрина в стиле сайтов про фильмы, блоками сверху вниз (экраны `Light` и `Main`):

1. **Сейчас читаешь**: HeroCard с обложкой, страницей, стежковой полосой, кнопкой «Начать сессию» (при нескольких книгах листаются свайпом, точки-индикаторы)
2. **Сегодня** (кольцо) и **серия** дней
3. **Дедлайн**: страниц в день и статус «в графике»
4. **Дальше в очереди**: ряд обложек с номерами
5. **Неделя**: столбики по дням с линией цели
6. **План на год**: корешки книг, «N из M»
7. **Цитата дня**
8. **Недавно прочитано**: обложки и оценки

**Готово, когда:** вся главная собирается из реальных данных и листается одной рукой.

## ФАЗА 6 — Цели ⬜

- Дедлайн по книге: «закончить за N дней» превращается в норму страниц в день, пересчитывается каждый день по факту («пропустишь день: завтра норма вырастет до N»)
- Диалог «Изменить дедлайн» (макет нужен до фазы)
- Исключение дней без чтения из расчёта
- Дневная цель в страницах (сейчас 30), недельная считается из неё
- Годовая цель: число книг (сейчас 24) и прогресс
- Настройки целей
- Показ целей на главной, странице книги и в статистике

**Готово, когда:** при пропуске дня завтрашняя норма корректно растёт, цель года отражает реальные прочитанные книги.

## ФАЗА 7 — Статистика ⬜

- Экран `Stats`: переключатель периода (неделя, месяц, год, всё время) и навигация по периодам
- Плитки: страницы, время, скорость, средний заход, книги, серия
- Календарь чтения (тепловая карта по дням)
- Страницы по неделям
- «Когда читаешь»: утро, день, вечер, ночь
- Цель года с прогрессом
- Итоги года: книги, страницы, часы, самая длинная книга, любимый жанр (макет нужен до фазы)

**Готово, когда:** все метрики считаются верно на реальных данных и помещаются в экран без горизонтальной прокрутки.

## ФАЗА 8 — Заметки и цитаты ⬜

- Экран `Notes`: типы (цитата, мысль, слово, фото), фильтры, группировка по дням, избранное
- Быстрое добавление из сессии («+ цитата», «+ фото») и с экрана заметок
- Фото страницы: съёмка и хранение в Supabase Storage
- Распознавание текста по фото через Claude Vision на сервере, выделение нужного фрагмента и сохранение как цитаты (макет съёмки и выбора нужен до фазы)
- Голосовая диктовка через микрофон клавиатуры Android (отдельная разработка не нужна)
- Поиск по всем заметкам, теги
- Цитата дня на главной
- Экспорт заметок в Markdown

**Готово, когда:** страница книги сфотографирована, фрагмент распознан и сохранён цитатой за минуту, поиск находит заметку.

## ФАЗА 9 — Завершение книги ⬜

- Экран «Книга прочитана»: оценка, короткий итог, даты, сколько часов ушло (макет нужен до фазы)
- Пауза и отказ от книги с причиной
- Архив прочитанного с сортировкой и фильтрами

**Готово, когда:** закрытие книги оформляется за один экран, данные попадают в статистику.
