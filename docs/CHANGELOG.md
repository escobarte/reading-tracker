## 2026-10-22 — Фаза 2: база и вход

**Сделано**
- Проект Supabase (регион Europe). Шесть таблиц (`books`, `readings`, `sessions`, `notes`, `goals`, `settings`), индексы, RLS на каждой, политики для `authenticated` по `user_id`, явные права (`grant`), для `anon` доступа нет. Миграция `supabase/migrations/0001_init.sql` выполнена владельцем.
- Клиенты `@supabase/supabase-js` и `@supabase/ssr`: браузерный, серверный, обновление сессии. `src/proxy.ts` (в Next.js 16 вместо `middleware.ts`) защищает все маршруты через `getClaims()`; без входа редирект на `/login`; manifest, `sw.js`, иконки и статика открыты.
- Экран `/login`: логотип `BookSpines`, слоган, карточка Email и Пароль, «глаз», состояния загрузки и ошибки, вход через server action `signInWithPassword`. Вариант AppShell `bare`. В Настройках кнопка «Выйти».
- Временная страница `/dev/db` (создать, показать, удалить тестовую книгу), доступна только после входа.
- Типы таблиц `src/lib/db/types.ts`, `.env.example`, исправлен `.gitignore` (`.env.example` попадает в git).
- Проверено владельцем на ПК и на телефоне по превью ветки: вход, запись и удаление, выход, закрытие без входа; RLS `true` на всех шести таблицах.
- Добавлен `docs/SETUP.md` (настройка Vercel, Supabase, ключей и порядок проверки веток).

**Решения**
- Вход по email и паролю, регистрация закрыта, аккаунт владельца создан в панели Supabase. Восстановление пароля и регистрация по почте отложены до появления своего домена (нужен Resend).
- Защита превью Vercel отключена (Vercel Authentication), чтобы превью открывались на телефоне.

**Отклонения от `DESIGN.md`**
- Добавлены токены `--spine-1..4` (значения из `DESIGN.md`, раздел 2) и иконки `eye`, `eye-off`.
- В `settings` нет `created_at`, только `updated_at` (одна строка на пользователя).

**Известное**
- На ПК контент сдвинут вправо, а не по центру, как на макете. Мелкая правка (`fix/desktop-centering`).
- `/dev/db` доступна в production после входа; удалить в Фазе 3.

## 2026-10-20 — Фаза 1: каркас

**Сделано**
- Next.js 16 (App Router), TypeScript, Tailwind CSS v4. Структура `src/app`, `src/components/{ui,layout}`, `src/lib`, `src/i18n`.
- Токены и две темы из `DESIGN.md` (светлая по умолчанию), плетение фона, шрифты Spectral и IBM Plex Mono.
- i18n RU/EN со словарями и переключателем.
- PWA: manifest, иконки (временные), service worker. Установка на домашний экран работает.
- Оболочка: AppShell, BottomNav (Главная, Книги, Старт, Заметки, Статистика), PageHeader.
- UI-компоненты: Icon, Button, IconButton, AddButton, Pill, Chip, SegmentedControl, Input, Stepper, Card, HeroCard, GoalCard, StitchBar, StitchRing, StatTile, Cover.
- Экраны-заглушки, рабочие настройки языка и темы, витрина компонентов `/dev/kit` (только в режиме разработки).
- Деплой на Vercel: https://reading-tracker-one-steel.vercel.app. Проверено на Galaxy S25.
- Правило про имена веток и ссылка на макеты записаны в `STATE.md`.

**Отклонения от `DESIGN.md`**
- Свой лёгкий i18n вместо next-intl.
- Тема и язык хранятся в cookie (без вспышки при загрузке), а не в localStorage.
- Радиусы Chip, Input и SegmentedControl взяты с нижней границы допустимого диапазона.
- Вариант `Cover` с картинкой реализован, но пока не используется.
- Корневой `README.md` заменён заглушкой со ссылкой на `docs/README.md`.

**Известное**
- На компьютере приложение показано узкой колонкой по центру. Отдельный вид для ПК: сделан в Фазе 1.5.
