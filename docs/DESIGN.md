# DESIGN — Reading Tracker

> Единственный источник по внешнему виду приложения. Claude Code берёт цвета, шрифты, размеры и правила компонентов только отсюда.
> Эталон композиции экранов: макеты (холст «Главная Reading Tracker», 12 артбордов: 9 телефонных и 3 для ПК). При расхождении побеждает этот файл, затем макет.
> Версия 1.1 · 2026-10-20 (добавлен вид для ПК)

---

## 1. Концепция

**Стичпанк-лайт:** книга, сшитая из механизмов. По мотивам мультфильма «9»: мешковина, стежки, заклёпки, тёплый свет.
Стиль лёгкий, для ежедневного использования одной рукой. Фактура задаётся тонким «плетением» фона, пунктирными «стежками» и редкими заклёпками. Тяжёлых текстур нет.

- **Тема по умолчанию: светлая.** Тёмная есть как вариант (переключатель в настройках).
- **Mobile-first.** Эталонная ширина 390 px. Телефонный вид работает до 1023 px. От 1024 px включается отдельный вид для ПК (раздел 7.1).
- **Один фирменный приём:** стежковая полоса прогресса. Остальное сдержанно.
- Обложки книг остаются главными цветными пятнами экрана.

## 4. Отступы, радиусы, границы

- **Сетка 4 px.** Шкала: 4, 6, 8, 10, 12, 14, 16, 20, 24.
- Поля страницы по бокам 20. Верхний отступ 20.
- Промежуток между блоками: 24 на главной, 16 на остальных экранах.
- Внутренний отступ карточки 16 (компактной 14). Промежутки внутри: 12, 8, 6.

**Радиусы:** карточка 16 · строка списка 14 · кнопка 12 (большая CTA 12–16) · таб-пилюля 22 (высота 44) · чип 12–13 · поле ввода 12 · segmented 12–14 снаружи, 9–11 внутри · круглые кнопки 50%.
Обложка: слева 3–5, справа 6–10 (чем крупнее, тем больше).

**Границы:**
- Карточка: `1px solid var(--line)`.
- «Стежок» (пунктир): `1.5px dashed var(--stitch)` для вторичных кнопок, иконок, чипов (чип `1px`).
- Дедлайн, цель: `1.5px dashed var(--deadline)`.
- Выбранный элемент: `2px solid var(--accent)`.

**Фон приложения (плетение):**
`background-color: var(--bg); background-image: repeating-linear-gradient(0deg, var(--weave) 0 1px, transparent 1px 4px), repeating-linear-gradient(90deg, var(--weave) 0 1px, transparent 1px 4px);`

**Тени:** обложка `0 8px 16px` (светлая `rgba(60,40,10,.35)`, тёмная `rgba(0,0,0,.5)`) · основная кнопка `0 6px 16px` акцент с альфой .35 (в тёмной вместо тени свечение `0 0 26px` акцент .3) · главная карточка светлой темы `0 8px 20px rgba(92,59,30,.18)`.

## 5. Иконки

Только встроенный SVG, 24×24, `stroke: currentColor`, толщина 1.8, `round` на концах и стыках. Без emoji, без иконочных шрифтов.
Набор: главная, книги (три корешка), старт (треугольник, заливка), заметки (лист со строками), статистика (три столбика), настройки (бегунки), поиск, плюс, закрыть, назад, шеврон вниз, пауза, стоп (квадрат), камера, цитата, избранное (звезда), галочка, «ещё» (три точки), перетаскивание (шесть точек), экспорт.

## 6. Компоненты

### StitchBar — стежковая полоса прогресса
Высота 10, радиус 5. Дорожка: `repeating-linear-gradient(90deg, var(--accent)@.28 0 7px, transparent 7px 11px)`. Заполнение: тот же рисунок, но `--accent` без прозрачности, ширина в процентах. Справа подпись процента (Plex Mono 13).

### StitchRing — стежковое кольцо
SVG, поворот −90°. Дорожка: окружность, `stroke --accent@.28`, штрих `6 5` (маленькое, r=40, толщина 7) или `8 7` (большое, r=126, толщина 10). Прогресс: окружность `pathLength="100"`, `stroke --accent`, `stroke-dasharray="N (100−N)"`, `stroke-linecap: round`. Значение в центре: Plex Mono.

### Card — карточка
`--surface`, граница `1px --line`, радиус 16, отступ 16.
**HeroCard (сейчас читаешь):** + радиальное свечение справа сверху (`radial-gradient(circle at 100% 0, --accent@.2 (светлая .14), transparent 55%)`), внутренняя пунктирная рамка (`inset: 5px`, `1.5px dashed --accent@.28–.35`, радиус 12), четыре заклёпки 8×8 в углах на расстоянии 8 (`radial-gradient(circle at 35% 30%, #d9c9a8, #6b5a43 70%)`, в светлой `#f4e3b8` и `#8c7650`).
**GoalCard (дедлайн, цель):** граница `1.5px dashed --deadline`.

### Button
- **Primary:** высота 52–58 (на экране сессии 68), фон `--accent`, текст `--accent-on`, вес 700, радиус 12–16, тень по разделу 4.
- **Secondary:** высота 52, граница `1.5px dashed --stitch`, фон `--surface`.
- **IconButton:** 48×48, круг, `1.5px dashed --stitch`, фон `--surface`.
- **AddButton:** 48×48, круг, фон `--accent`, плюс цвета `--accent-on`.
- **Pill (полки, фильтры):** высота 44, радиус 22; активная: фон `--accent`, текст `--accent-on`, вес 700; неактивная: `1.5px solid --line`, фон `--surface`. Счётчик справа в Plex Mono 12.
- **TextButton:** без фона, минимальная высота 44.
- Минимальная зона касания везде 44×44.

### Chip
Plex Mono 12, высота 24 (26 на странице книги), отступы 0 10, радиус 12–13, `1px dashed --stitch`, текст `--muted`. Статус «в графике»: `1px solid --ok`, текст `--ok`, галочка 12 px. Тип заметки «цитата»: заливка `--accent`, текст `--accent-on`.

### Segmented
Высота 44–48, отступ 3, радиус 12–14, `1.5px solid --line`, фон `--surface-2`. Активный сегмент: `--accent`, текст `--accent-on`, 700. Неактивный: прозрачный, `--muted`.

### Input
Метка сверху: Plex Mono 12, `--muted`. Поле: высота 46–54, `1.5px solid --line`, фон `--input`, радиус 12, текст Spectral 17–18. Фокус: `2px solid --accent`. Числовые поля: Plex Mono.

### Stepper (ввод страницы)
Кнопки «−» и «+»: 64×88, радиус 14, `1.5px dashed --stitch`. Центральное поле: высота 88, `2px solid --accent`, фон `--input`, число Plex Mono 56. Под ним ряд быстрых кнопок `+5 +10 +20`, высота 44, `1px dashed --stitch`.

### BottomNav
Высота 84, `border-top: 2px dashed --stitch`, фон `--nav`, учитывает safe-area снизу. Пять пунктов: Главная · Книги · **Старт** · Заметки · Статистика.
Обычный пункт: иконка 24 + подпись 12, зона 64×56. Активный: цвет `--accent`, подпись 700. Неактивный: `--muted`.
**Старт:** круг 60 с треугольником, поднят на 30 над панелью (`margin-top: -30px`), фон `--accent`, «ободок» `box-shadow: 0 0 0 4px var(--nav), 0 0 0 6px var(--accent)` плюс тень/свечение. Подпись «Старт» 700.

### Cover — обложка
Если есть `cover_url`, показывается картинка с тем же радиусом, тенью и накладкой корешка. Если нет, рисуется CSS: цвет по хэшу из палитры обложек, слева «корешок» (`linear-gradient(90deg, rgba(0,0,0,.4) 0 5px, rgba(255,255,255,.07) 5px 7px, transparent 7px)`), внизу пунктирная линия `rgba(241,230,209,.45)` и название Spectral 700 (14–20 в зависимости от размера).
Размеры: hero 120×170 · страница книги 150×220 · очередь и «недавно» 100×146 · строка списка 56×82 · результат поиска 44×64 · сессия 72×104.
Номер в очереди: круг 24, `--accent`, mono 12, смещён на −6/−6 от угла.

### BookRow (строка списка)
Фон `--surface`, `1px --line`, радиус 14, отступ `10 6 10 12`. Слева номер (mono 14, ширина 16), обложка 56×82, текст (название 17 / автор 13 / формат и страницы mono 12), справа ручка перетаскивания 44×56. Первая в очереди: граница `1.5px --accent` и метка «следующая».

### StatTile
Фон `--surface`, `1px --line`, радиус 16, отступ 14. Подпись mono 12 `--muted`, число mono 34. Плитка серии: `1.5px dashed --accent`.

### WeekBars (столбики по дням и неделям)
Столбик: ширина 24 (главная) или 36 (статистика), радиус `5 5 2 2`, цвет `--bar`, «швы»: `repeating-linear-gradient(0deg, transparent 0 6px, --bg@.45–.55 6px 8px)`. Сегодня или текущий период: `--accent` с мягкой тенью/свечением. День без чтения: пунктирная чёрточка `2px dashed --stitch`. Линия цели: `1.5px dashed --text@.4`, подпись «цель N» справа (mono 12). Значения над или под столбиками (mono 12), подписи дней 13.

### Heatmap
Сетка 7 колонок (Пн–Вс), клетка высотой 38, радиус 7, промежуток 4. Цвета по уровням из раздела 2. Сегодня: `box-shadow: 0 0 0 2px var(--surface), 0 0 0 4px var(--text)`. Цифр в клетках нет, только цвет (декоративно, `aria-hidden`); итог дублируется текстом («20 из 23 дней»).

### YearSpines (план на год)
24 корешка шириной 10, промежуток 3, высоты 46–64 вперемешку. Прочитанные закрашены цветами корешков, оставшиеся: `1.5px dashed --stitch`. Строка итога: число mono 38 и «из N книг».

### NoteCard
Как Card (радиус 16, отступ 14). Сверху чип типа (цитата, мысль, слово, фото) и звезда-избранное в зоне 44×44. Текст цитаты и мысли: Spectral курсив 18. Слово: Spectral 24/700 и значение 16 `--muted`. Подпись «книга · стр. N»: mono 12. Миниатюра фото: «листок» `--paper` 56×74, поворот ±3°, тень, «строчки» из полосок.

### HistoryList
Карточка, строки разделены `1.5px dashed --line`. Строка: слева дата (Spectral 16/700) и мелкая строка mono 12 (минуты, страницы от → до), справа число страниц mono 16.

## 7.1 Компьютер (от 1024 px)

Отдельный вид, не растянутый телефонный. Те же токены, компоненты и тексты, меняется только компоновка. Тема на макетах светлая, тёмная собирается из токенов. Эталон: артборды `DeskHome`, `DeskLibrary`, `DeskStats` (ширина 1440), картинки `docs/mockups/desktop-home.png`, `desktop-library.png`, `desktop-stats.png`.

**Переключение:** по ширине окна, брейкпоинт 1024 px. Меньше: телефонный вид с BottomNav без изменений. Больше: боковая панель, BottomNav скрыта.

**Каркас**
- Боковая панель слева, ширина 248, на всю высоту, фон `--nav`, `border-right: 2px dashed --stitch`, внутренний отступ `28 16 24`.
- Контент справа: отступ `32 40 40`, внутри контейнер `max-width: 1200` по центру. Фон с плетением на всём окне.
- Промежуток между блоками 24 (в плитках статистики 16). Отступ карточки 20 (на телефоне 16).

**Боковая панель, сверху вниз**
1. Логотип: метка «Reading» (label, `--accent`) и «Tracker» Spectral 28/700.
2. Кнопка «Начать сессию»: Primary, на всю ширину, высота 52, иконка старта. Заменяет круглую «Старт» из BottomNav.
3. Навигация: Главная, Книги, Заметки, Статистика. Пункт: высота 48, радиус 12, иконка 24 + подпись Spectral 17, промежуток 12. Активный: `1.5px solid --line`, фон `--surface`, цвет `--accent`, вес 700. Неактивный: прозрачный, `--muted`.
4. Внизу (прижато): мини-карточка «Сегодня N из M стр.» со StitchBar и «серия N», под ней кнопка «Настройки» (высота 48, `1.5px dashed --stitch`, прозрачная).

**Шапка страницы:** заголовок Spectral 34/700; справа действия (поиск, «Добавить книгу», переключатель периода). Кнопка добавления на ПК текстовая: Primary высотой 48 с плюсом и подписью.

**Главная** (сетка 3 колонки, промежуток 24)

## 8. Доступность и правила

- Контраст текста не ниже 4.5:1 (крупный 3:1). Значения токенов подобраны под это, при изменении палитры перепроверять.
- Зона касания не меньше 44×44.
- Кнопки, ссылки и поля только настоящими элементами (`button`, `a`, `input` с `label`). Декор (`aria-hidden="true"`): рамки, заклёпки, кольцо, корешки, календарь.
- Кнопки-иконки с `aria-label`.
- Цвет не единственный носитель смысла (рядом текст или форма).
- Учитывать `prefers-reduced-motion` (анимации только короткие и мягкие).
- Нет emoji в интерфейсе.
- Нижняя навигация и CTA учитывают `env(safe-area-inset-bottom)`; высота экрана `100dvh`.
- Весь текст интерфейса через словари RU/EN, без «зашитых» строк в компонентах.
