## ПРОЕКТ

Личное PWA-приложение для учёта чтения книг, замена базы «Reading Now» в Notion. Только для владельца, только Android, только онлайн.
Приложение **ведёт учёт**, ридера внутри нет: книги читаются в бумаге или в своей читалке.

**Главный приоритет:** удобство на мобильном, одной рукой. ПК второстепенен, но у него свой простой вид (боковая панель и колонки, Фаза 1.5), а не растянутый телефон.
**Стиль:** лёгкий стичпанк (по мотивам мультфильма «9»), светлая тема по умолчанию, тёмная как вариант.

## РОЛИ

## ЖЁСТКИЕ ПРАВИЛА

1. **Git только владелец.** Claude Code не делает commit, push, merge, reset, branch. Он сообщает, что изменено, владелец коммитит сам.
   **Имя ветки:** перед каждым новым добавлением (фаза, функция, исправление) штаб и Claude Code предлагают имя ветки. Формат: `phase-N/кратко` для фаз, `feat/кратко` для функций, `fix/кратко` для исправлений, `docs/кратко` для документов. Латиница, строчные, слова через дефис. Пример: `phase-1/skeleton`. Ветку создаёт владелец; если работа уже началась, `git switch -c имя` переносит изменения в новую ветку.
2. **Mobile-first.** Любое изменение сначала проверяется в мобильном viewport (360–430 px). Десктоп только адаптируется.
3. **Дизайн только по токенам** из `docs/DESIGN.md`. В компонентах нет hex-цветов, «магических» отступов и радиусов. Чего нет в `DESIGN.md`, не придумывается: выбирается самое простое решение по токенам и фиксируется в отчёте.
4. **Весь текст интерфейса через словари RU/EN.** Хардкод строк в компонентах запрещён.
5. **Ключи API только на сервере.** Google Books, Claude, Supabase service key не попадают в браузер. Запросы идут через серверные route handlers.
6. **Одна книга = одна запись.** Чтение хранится отдельно: прочтения и сессии. Никаких дублей книги по неделям.
7. **Производные поля не хранятся.** Текущая страница, остаток, прогресс, скорость, серия считаются из сессий.
8. **Ввод прогресса в пару касаний:** от главной до сохранённой сессии минимум действий.
9. **Зоны касания не меньше 44×44**, у иконок `aria-label`, контраст по `DESIGN.md`.
10. **Только онлайн.** Офлайн-режима и синхронизации нет.
11. **Row Level Security** на всех таблицах с момента их создания.
12. **Новые зависимости только по необходимости** и с записью в отчёте.
13. **Ритуал завершения фазы** (ниже) выполняется всегда, без исключений.

## РИТУАЛ ЗАВЕРШЕНИЯ ФАЗЫ

*До начала работы:* предложено имя ветки, владелец создал её.

1. Claude Code проверяет: `lint`, `typecheck`, `build`.
2. Claude Code сообщает, что сделано, какие файлы изменены, что отклонилось от `DESIGN.md`.
3. Владелец проверяет на телефоне (или в мобильном режиме браузера).
4. Владелец делает commit в ветке фазы и сливает её в основную.
5. Запись в `docs/CHANGELOG.md`.
6. Обновление этого файла: «ГОТОВО» и «ЧТО ДАЛЬШЕ». Статус фазы в `PLAN.md`.

## РЕШЕНИЯ (принятые)

- Формат: **PWA**, не нативное приложение. Платформа: Android.
- Только онлайн, только для владельца, без импорта из Notion.
- Языки интерфейса: русский и английский с переключателем. Книги и заметки на русском, английском, румынском.
- Книги: бумажные и электронные (прогресс страницей или процентом). Аудио нет.
- Перечитывание есть, но редкое: у книги может быть несколько прочтений.
- Цели: дедлайн по книге (норма страниц в день пересчитывается каждый день, можно исключить дни недели без чтения; срок «за N дней» считается включая сегодня), дневная цель в страницах, годовая цель в числе книг (считаются закрытые прочтения за календарный год). Сейчас 30 страниц в день и 24 книги в год, хранятся в таблице `goals`, меняются в настройках.
- Регион функций Vercel: Европа, рядом с Supabase (eu-west-1, Ирландия). Иначе каждый запрос к базе идёт через океан.
- Цитаты и заметки: типы цитата, мысль, слово, фото. Фото страницы с распознаванием текста через Claude Vision. Диктовка голосом через клавиатуру Android.
- Напоминания push отменены владельцем (2026-11-08). Фаза 10 не делается.
- Время: UTC в базе, показ в Europe/Bucharest, неделя с понедельника.
- Проверка на телефоне: Vercel с первой фазы. Каждая ветка получает свою https-ссылку, основная ветка постоянный адрес. PWA ставится только по https, адрес по IP домашней сети не подходит. На проекте Vercel отключить Deployment Protection (Settings → Deployment Protection), иначе превью требуют вход в Vercel и установка PWA может не сработать. GitHub и Vercel настраивает владелец.
- Вход: через Google (основной) и по email и паролю (запасной). Регистрация новых пользователей закрыта, аккаунт владельца создан в панели Supabase, Google привязан к его почте (`SETUP.md`, 3.1). Сессия хранится в браузере и не требует повторного входа. Почтовый сервис (Resend и т.п.) не нужен: письма приложение не шлёт.
- Дизайн: светлая тема по умолчанию, лёгкий стичпанк, главная из 8 блоков, кнопки «Старт» и «Начать сессию».

## ЧТО ДАЛЬШЕ

1. Владелец: заменить документы в `docs/` и `README.md`, слить `phase-11/polish` и `phase-11/export` в `main`, удалить пустую папку `new-icons`.
2. **Фаза 11C — финальная проверка.** Полный проход по приложению на телефоне: установка PWA и иконка, скорость, пустые и ошибочные состояния, обе темы, оба языка, ПК-вид. Найденное чиним малыми правками. Свой домен и боевые переменные окружения (по желанию, см. `SETUP.md`).
3. После этого приложение считается готовым к ежедневному использованию. Идеи на потом: импорт из бэкапа, сканирование ISBN, годовые «открытки».

**Известное после Фазы 4 (не блокирует, разобрать в подходящей фазе):**
- `/session?book=ID` по прямой ссылке на прочитанной книге сразу создаёт новое прочтение без вопроса.
- Переключатель прочтений в «Вся история» не проверен вживую.
- Экраны выбора книги, ручного ввода, правки сессии и всей истории без макетов (собраны из токенов).
- Число страниц и жанр подставляются не всегда; жанр от Google на английском.
- Удаление книги и сессии подтверждается встроенным окном браузера `confirm()`.
- Блок «Дедлайн» на главной показывает первую книгу с дедлайном, не синхронизирован со свайпом карусели.
- Новая дневная или годовая цель считается с сегодняшнего дня, прошлые дни не пересчитываются.

Отложено: регистрация и восстановление пароля по почте (нужны домен и Resend), записано в `SETUP.md`, раздел 8.
